# R2 递归下挖：从现象挖到机制

## 1 停止条件

**碰到机制就停。** 机制的可操作定义：

> 你能说出「**因为 X，所以 Y 必然发生**」，且 X 是一个**结构**而不是一次**观测**。

对不上这个句式，就是还没到机制，继续挖。

---

## 2 递归的三个问题（对每个子问题都问）

### 问 A：它是**怎么**变成这样的？（机制）

不是「它是什么」，是「它**为什么**必然是这样」。

### 问 B：如果修好这个，**同类问题会不会在别处再犯**？

会 → 你挖的是实例，不是机制。
不会 → 可能到了机制层。

### 问 C：这个东西**信任的前提**是什么？谁在违反它？

这是最容易被跳过、但命中率最高的一问。

真实案例：
> `RollbackTo` 的前提是「检查点与回滚之间没有别的写者」。
> 代码里有两道防线（锁 + 已同步集合）。
> 但第三处创建实体的路径（采纳分支）**不在这两道防线里** —— 缺陷在现场之外。

**判据**：把代码注释里带「前提 / 必须 / 不许 / 只有」的句子抽出来，
逐条去找违反者。**缺陷通常在前提的对面，不在前提所在的文件里。**

---

## 3 递归树长什么样

```
核心问题
├─ 子问题 1  [L3]
│   ├─ 现象：XXX 不一致
│   ├─ 机制：因为 YYY，所以必然 ZZZ
│   └─ 前提：信任 AAA；违反者：BBB（在另一个文件）
├─ 子问题 2  [L2]
│   └─ ...
```

**每个节点必须有**：
- 层号（L0–L5）
- 现象（可观测）
- 机制（因果句）
- 判据（怎么验）

**没有机制的节点不许收工。** 只写现象的节点 = 扁平化的最小单位。

---

## 4 三个反复出现的深层机制

### 机制 1：用一致性代替真实性

`A == B` 是**等价关系**。

> 对任意常数 c，把**全体 A 和 B** 同时替换为 c，检查输出**完全不变**。
> ⇒ 存在无穷多错误配置与正确配置产生相同结果。

**推论（反直觉）**：错误传播 = 复制 = **提高一致性**。
一个错数被抄到 8 个文件，检查全绿。**错得越广，越像真的。**

**破法**：把锚换到「算术 / 代码 / 运行时输出」。
判据：**把被检查的文档全删，这条检查还能跑吗？**

### 机制 2：条件在高熵处先丢

一个数字的完整信息 = 数值 + 语料 + 口径 + 日期 + 命令。
传播时**先丢高熵部分**（口径、命令）。

原因不是能力，是**激励**：写数值让文档「有料」，写条件让文档「冗长」。

**破法**：数字必须与条件**同格出现**，且报**单位量**（不变量）而非总量（可变量）。

### 机制 3：机制被拆成两半，接口退回最底层

代码里有两套模型，各管一半：
```
模型 A：管「链」（核心 + N 个补充）
模型 B：管「候选」（一个关注点 + 它的关系）
```
**A 没有「给我候选」的方法，B 不知道链。** 谁也接不上谁。
结果：接口只好退回**最底层的单个原语**（只走 1 步、只给 ID）。

**症状**：接口「能用」但「僵硬」；上层模型全部 `生产调用 = 0`。

**破法**：给 A 补上「取候选」的方法，让它能自己走完一条链。
判据：`grep 生产代码 | 上层函数名` 必须 > 0。

## 5 递归深度自检

问自己三个问题：

1. **我现在能在纸上一句话说出机制吗？**（不能 → 继续）
2. **如果我把这个机制改掉，同类症状会不会全部消失？**（不会 → 挖错了）
3. **我的结论会不会在换一份代码后就失效？**（会 → 你挖的是实例）

---

## 6 强制动作：回去读原始需求

**你自己的理解会漂移。用户的原话不会。**

当出现以下任一情况，**停止推理，去读最初的原文**：
- 两个解释都说得通；
- 递归卡住；
- 你觉得「这设计很奇怪，为什么当初这么做」。

**真实案例**：一个项目里所有人（含文档作者）都认为「维 = 数嵌套层数」，
直到有人翻出一篇标着「已作废」的旧稿，里面用户的原话是：
> 「维无轴，维就是维……本身就只是一个标签而已，长度不是维度。」
> 「工具不计算维；工具交还含义。」

**一句话推翻整个方向。**

**判据**：每个关键结论，能否指到**用户原话**或**实测行为**？
两样都指不到 → 标记为推测。

---

## 7 一个必须记录的东西：**你自己犯的错**

递归过程中你会判断错。**把错的也写进文档。**

理由不是自谦，是**下一个人（或下一个 AI）会重犯同一个错**。
写成「我曾经以为是 X，实测是 Y，因为 Z」，比只写 Y 有效十倍。
