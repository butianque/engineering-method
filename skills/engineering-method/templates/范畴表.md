---

## 表 A 术语表（≥5 行）

| 词 | 在本系统里的唯一定义 | 一义多名（禁用的写法） |
|---|---|---|
| 凭证 | 一份可以拿去调上游的登录态 | credential / token / session（混用即违规） |
| | | |

**规则**：一个词只有一个意思；一个意思只用一个词。
**发现两个词指同一件事 ⇒ 立刻合并，不许"知道就行"。**

---

## 表 B 不变量（≥3 条，且每条都有验法）

**不变量 = 永远为真的断言。不是愿望。**

| # | 不变量 | 怎么验（命令或断言） |
|---|---|---|
| 1 | 重启后已写入的数据仍可读出 | `bash 验收.sh --case restart` |
| 2 | 任何一次写入都不会修改已有行 | `grep -c '^\s*UPDATE\|^\s*DELETE' schema.sql` 期望 0 |
| 3 | | |

> ❌ 「系统应该稳定」
> ✅ 「任何一次写入都不会修改已有行」

**为什么必须有**：不变量是"越用越窄"的锚。
没有它，第 10 次改动时没人能判断"这算不算破坏原有承诺"。
