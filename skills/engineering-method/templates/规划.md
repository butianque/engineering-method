# 规划

> 规划回答三件事：**分几步、每步的边界在哪、哪一步之后可以停。**
> 不是排期表，不是甘特图 —— 是"每个阶段怎么独立交付"。

---

## 一、阶段切分

**规则：每个阶段必须是一个「垂直切片」** —— 从入口到产物都是完整的，
不是一个横切层（"先写所有 model，再写所有 service"）。

| # | 阶段名 | 产出什么（可交付物） | 退出判据（一条命令/一次操作） | 依赖 |
|---|---|---|---|---|
| 1 | | | | — |
| 2 | | | | 1 |

**退出判据的三种合法形式：**

```
① 命令退出码 0        bash 验收.sh --case <阶段名>
② 一次可观测操作        "从入口打一次，返回 200 且体里有 X"
③ 人工签收 + 记录       "人确认后写 .runs/signoff-<阶段>.md"
```

**⇒ 写不出退出判据的阶段，不是阶段，是一步里的两半。合并它。**

---

## 二、阶段依赖

| 类型 | 说明 | 要求 |
|---|---|---|
| 必须串行 | 后者的输入是前者的产物 | 写明输入是什么字段/文件 |
| 可并行 | 互不依赖 | 写明为什么互不依赖 |

**禁止的依赖（这条有实证依据）：**

```
❌ 阶段 N+1 依赖阶段 N 才能验证
   ⇒ 那说明 N 没有独立判据，它其实不是一个阶段
```

---

## 三、人判断点（哪几步不许自动化）

| # | 阶段 | 为什么必须人签 | 签什么 |
|---|---|---|---|
| 1 | | | |

**必须人签的典型位置：**

- **系统设计 → 程序设计** 之间（结构决策，错了后面全歪）
- **方案选型**（策划里的 A/B 选择）
- **不可逆操作前**（删数据、改线上配置、发版）

**⇒ 24 小时自动化 ≠ 没有人。是人不进日常回路，只守这几个出口。**

---

## 四、自检

- [ ] 每个阶段都有退出判据，且无空阶段
- [ ] 每个阶段是垂直切片（从入口到产物）
- [ ] 没有"阶段 N+1 依赖 N 才能验证"的情况
- [ ] 人判断点写出来了，且不超过 3 个
- [ ] 阶段数 ≤ 7（超过就说明切太细或没想清）
